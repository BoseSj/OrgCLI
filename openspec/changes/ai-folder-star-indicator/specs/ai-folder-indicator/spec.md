## Purpose

Displays visual star badges beside AI-suggested folder categories in organizer scan CLI interfaces to clearly distinguish model recommendations from deterministic rules.

## ADDED Requirements

### Requirement: Visual Star Badge for AI-Suggested Folders in Static Scan
The system SHALL display a star icon/emoji (`⭐`) beside folder category titles in the static organization plan table whenever that folder group was suggested by an AI model.

#### Scenario: Rendering table title for AI-suggested folder
- **WHEN** the system displays the proposed organization plan table and a folder group was suggested by an AI model
- **THEN** the system includes a star emoji beside the folder title (e.g., `📁 ⭐ <FolderName>`).

#### Scenario: Rendering table title for rule-suggested folder
- **WHEN** the system displays the proposed organization plan table and a folder group contains only deterministic rule-based classifications
- **THEN** the system displays the standard folder title without a star emoji (e.g., `📁 <FolderName>`).

### Requirement: Visual Star Badge in Interactive Plan Review
The system SHALL display a star icon/emoji (`⭐`) beside AI-suggested folder headers and in folder reassignment suggestions during interactive plan review.

#### Scenario: Viewing group header in interactive plan view
- **WHEN** the interactive plan review renders a folder group whose proposals were generated by an AI model
- **THEN** the group title renders a star emoji beside the folder name.

#### Scenario: Browsing move destination suggestions
- **WHEN** the user initiates folder reassignment in interactive mode and suggestions include categories originating from AI proposals
- **THEN** the suggestion list displays a star indicator beside AI-suggested folder options.

### Requirement: AI Suggestion Metadata Tracking
The system SHALL record whether each file organization proposal was generated by an AI model or by deterministic rules.

#### Scenario: Successful AI model classification
- **WHEN** a file is classified using an AI provider model
- **THEN** the resulting proposal marks the item as AI-suggested (`is_ai_suggested = True`).

#### Scenario: Deterministic rule classification or rule fallback
- **WHEN** a file is classified using deterministic extension rules or when an AI provider fails and falls back to rules
- **THEN** the resulting proposal marks the item as not AI-suggested (`is_ai_suggested = False`).
